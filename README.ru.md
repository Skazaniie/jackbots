## Что это

Jackbox-игры рассчитаны на живых людей с телефонами. JackBOTS подключается к серверу комнат Jackbox так же,
как браузер на телефоне игрока, и получает те же экраны: вопрос, варианты ответа, голосование.
Текст уходит языковой модели, ответ возвращается в игру. Бот не видит ничего сверх того, что увидел бы человек.

Можно добить компанию до нужного числа игроков, устроить матч «люди против ботов» или просто посмотреть,
как разные модели пытаются шутить. Работает и с оригинальными английскими играми (jackbox.tv), и с русской локализацией — боты отвечают на языке игры.

Нужен свой ключ к API модели: OpenAI, OpenRouter, DeepSeek, Google Gemini или локальная модель через Ollama / LM Studio.
Подойдёт любой сервер с эндпоинтом `/chat/completions`.

## Игры

| Игра | Пак | Что делают боты |
|---|---|---|
| **Смехлыст 2** (Quiplash 2) | Party Pack 3 | пишут ответы, голосуют, проходят финал: слово, аббревиатура, комикс |
| **Нашшпионаж** (Guesspionage) | Party Pack 3 | угадывают проценты, выбирают «больше/меньше», собирают топ в финале |
| **Смертельная вечеринка 2** (Trivia Murder Party 2) | Party Pack 6 | отвечают на вопросы викторины и пытаются выжить в испытаниях |
| **Выжить в интернете** (Survive the Internet) | Party Pack 4 | пишут ответы, перевирают чужие, подписывают фото (с vision-моделью — глядя на картинку) |

Игра определяется сама по коду комнаты. Остальные игры пока не поддерживаются.

## Установка

### Windows

1. Скачай `JackBOTS.exe` со страницы [последнего релиза](https://github.com/Skazaniie/jackbots/releases/latest).
2. Положи его в отдельную папку и запусти. Откроется консоль и браузер с панелью `http://127.0.0.1:4791`.
3. Пока окно консоли открыто, панель работает. Закрыл окно — боты вышли.

Рядом с exe появятся папки `config` (настройки и ключи) и `logs`. При обновлении просто замени exe —
настройки останутся.

Windows может показать «Система Windows защитила ваш компьютер»: у exe нет платной цифровой подписи.
Нажми «Подробнее» → «Выполнить в любом случае». Если не хочется запускать exe — ниже есть запуск из исходников.

### Android

1. Скачай `JackBOTS-<версия>.apk` из [релиза](https://github.com/Skazaniie/jackbots/releases/latest) прямо на телефон.
2. Открой файл и разреши установку из этого источника.
3. При первом запуске разреши уведомления: пока висит уведомление «JackBOTS работает», боты играют даже с выключенным экраном.

Нужен Android 8.0+ на 64-битном процессоре (arm64). Сервер ботов работает прямо на телефоне, компьютер не нужен.

### Из исходников

Нужен Python 3.11 или новее.

```bat
git clone https://github.com/Skazaniie/jackbots.git
cd jackbots
start.bat
```

`start.bat` при первом запуске создаёт окружение `.venv` и ставит зависимости. На Linux и macOS:

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m app
```

Флаг `--no-browser` отключает автоматическое открытие браузера.

## Как пользоваться

### 1. Ключи

Раздел «Ключи» — список провайдеров моделей. Для популярных уже заполнен адрес, остаётся вставить API-ключ
и нажать «проверить и загрузить список»: панель проверит ключ и подтянет доступные модели.
Любой другой сервис добавляется кнопкой «+ OpenAI-совместимый» — нужен только Base URL и ключ.

Ключи хранятся только у тебя: в `config/providers.json` рядом с программой. В «Дополнительно» —
таймаут, лимит токенов, стриминг и произвольные поля запроса (`extra_body`, заголовки).

<img src="docs/screenshots/providers.webp" alt="Раздел Ключи: список провайдеров и редактор">

### 2. Боты

У каждого бота своё имя (его увидят в игре), модель, характер и «фантазия» — температура модели.
Характер подставляется в промт, так что «бабуля», «душнила» и «стендапер» отвечают по-разному.
Здесь же отмечается, в какие игры бот ходит, и включается vision для моделей, которые понимают картинки.

<img src="docs/screenshots/bots.webp" alt="Раздел Боты: карточки ботов и редактор">

### 3. Тест моделей

Прежде чем звать ботов в игру, стоит проверить, что модели успевают отвечать. Тест даёт всем ботам
одно задание и показывает реальное время ответа против лимита. В Jackbox на ответ мало времени,
и медленная модель просто не успеет.

<img src="docs/screenshots/test.webp" alt="Тест моделей: заезд ботов с временем ответа">

### 4. Игра

1. Запусти игру на компьютере или консоли и выбери её в меню пака.
2. Введи в панели четыре буквы кода комнаты с экрана игры.
3. Отметь, кто из ботов играет, и нажми «запустить ботов».

Боты зайдут в комнату, и в ленте «Что пишут» будут появляться их ответы и голоса.
Если в комнате нет людей, VIP-ом становится первый бот — тогда в панели появится кнопка
«Все в сборе — начать», которая нажимает за него «Начать игру».

### 5. Промты

Для каждой фазы каждой игры свой промт: что модель получает и в каком виде должна ответить.
У английской и русской версии игр отдельные наборы промтов. Переменные вроде `{вопрос}`, `{варианты}`, `{история}`
(в английских — `{question}`, `{options}`, `{history}`) вставляются кликом,
а справа видно, что именно уйдёт модели. «Вернуть текст по умолчанию» откатывает правки.

<img src="docs/screenshots/prompts.webp" alt="Раздел Промты: фазы игры, редактор и предпросмотр">

### 6. Настройки

- **Язык интерфейса** — английский или русский (по умолчанию английский).
- **Версия игры** — «Авто» выбирает язык ответа по тексту игры. «Английская» — ответы и ники только латиницей:
  английский клиент jackbox.tv выкидывает другие символы, и кириллический ответ просто не дошёл бы до игры.
  «Русская» — для русской локализации.
- **Дополнительно** — адрес сервера Jackbox и лог трафика игры.

## Если что-то не так

- **Бот не заходит в комнату.** Проверь код и то, что в комнате есть место. Некоторые игры не пускают новых игроков после старта.
- **Бот молчит или отвечает слишком поздно.** Посмотри время модели в «Тесте». Помогают более быстрая модель,
  меньший `max_tokens` в промте или провайдер ближе к тебе. В английской игре проверь, что «Версия игры» — «Авто» или «Английская».
- **«Ошибка» у провайдера.** Нажми «проверить» в «Ключах» — там будет ответ сервера: неверный ключ, нет денег на балансе, неверный адрес.
- **Подробности.** Лог сервера — `logs/server.log`, весь обмен с игрой — `logs/traffic-*.jsonl`.

## Разработка

```
app/          сервер: FastAPI + uvicorn
  main.py     HTTP API /api/* и WebSocket /ws, раздаёт web/ на /ui/
  session.py  сессия ботов в комнате, лента событий
  jackbox.py  клиент сервера комнат Jackbox (ecast api/v2)
  games.py    логика игр: что бот видит и что отвечает
  lang.py     язык игры, ответы латиницей, сообщения панели
  prompts.py  промты по умолчанию для английской и русской версии
  llm.py      OpenAI-совместимый клиент: keep-alive, прогрев, стриминг
  store.py    config/*.json и значения по умолчанию
web/          панель: index.html и ES-модули без сборки
  js/pages/   страницы game, bots, providers, prompts, test, settings
  js/i18n.js  язык интерфейса; русские строки — в js/i18n.ru.js
android/      Android-приложение: WebView + тот же app/ на Python (Chaquopy)
branding/     исходник иконки
tools/        selftest.py, build_exe.bat, build_icons.js
```

Перед коммитом: `python tools/selftest.py` — офлайн-проверка логики всех игр, должна закончиться строкой «OK».

Новая страница панели — модуль в `web/js/pages/` с `export default { id, title, icon, mount(root, ctx) }`
и строка в `PAGES` в `web/js/main.js`. В `ctx` приходят `params`, `signal` (отменяется при уходе со страницы)
и `replaceHash`. Тексты интерфейса пишутся по-английски как `t('Text')`, русский перевод — в `web/js/i18n.ru.js`.
Пресеты провайдеров и иконки — в `web/js/catalog.js`.

**Сборка exe:** `tools\build_exe.bat` → `dist\JackBOTS.exe`. Папка `config` в exe не попадает.

**Сборка APK:** нужны JDK 17, Android SDK и Python 3.13 в PATH.

```sh
cd android
gradle assembleRelease      # app/build/outputs/apk/release/app-release.apk
```

Код панели копируется в APK из корня репозитория при сборке. Для подписи своим ключом положи
`android/keystore.properties` (`storeFile`, `storePassword`, `keyAlias`, `keyPassword`), без него сборка подпишется debug-ключом.

**Иконки:** правится `branding/make_svg.py`, затем `python branding/make_svg.py && node tools/build_icons.js` (нужен `npm i sharp`).
